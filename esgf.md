# Route B: standardised Phase 1 data on ESGF

A CMOR-standardised subset of the Phase 1 simulations is published on ESGF (DKRZ node: [esgf-metagrid.cloud.dkrz.de](https://esgf-metagrid.cloud.dkrz.de)), with Met Office data at CEDA. The first release prioritises the most requested variables on the regular grid. The user guide for the release is on [Zenodo (record 17465311)](https://zenodo.org/records/17465311).

Use this route when you need citable files with CMIP-style metadata, or when a variable you need is not on the km-scale cloud.
